Implement the active feature spec from `.kiro/specs/<feature>/`.

Steps:

1. Read `requirements.md`, `design.md`, and `tasks.md`.
2. Implement the smallest coherent batch of unchecked tasks.
3. Update tests and run focused verification.
4. Mark completed tasks in `tasks.md`.

Rules:

- Keep code changes aligned with the written spec.
- If implementation reveals a design mismatch, update the spec before or alongside the code change.
